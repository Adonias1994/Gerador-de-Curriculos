**Gerador de Currículos On-line***

Projeto desenvolvimento para gerar currículos em PDF de forma simples on-line.

**Tecnologias Utilizadas**

**Front-End**
- HTML5: coleta de informações e estrutura da página;
- CSS3: estilo da página;
- JavaScript: interação da página;
**Back-End**
- Python: banco de dados.
